Mission 02 · 1,030 concrete cylinders crushed in a lab

What makes concrete
strong?

In 1918 an engineer, Duff Abrams, claimed that one number decides it: how much water you mix in per kilo of cement. Every dot in the picture is one tested cylinder; the curves are his rule, fitted to our data. We put his rule on trial.

1Is the 1918 rule still right? How much of the strength does that one ratio explain?
2Does the full recipe add anything? Do we predict new recipes better with every ingredient?
3Would a computer find the same rule if we let it pick from all the ingredients on its own?

More water, weaker concrete

Method: multiple linear regression by least squares (Lectures 12–13). Abrams' law f = A / Bw/b becomes linear after taking logs, so we fit

log fi = β₀ + β₁ (w/b)i + β₂ ai + β₃ ai² + εi,   a = log(age / 28)

Not fooling ourselves · 1

Raw strength breaks the model. Log strength fixes it.

A good model leaves leftovers (errors) that look like random noise around zero. Flip between the two versions.

!Raw MPa: the errors bend in a curve, and – cylinders get a negative predicted strength, which is impossible.
✓log MPa (Abrams' own form): the curve disappears, no impossible predictions, and no single cylinder pulls the fit around (largest influence, Cook's D = –).
Show the statistics

Method: regression diagnostics (Lecture 13). Residuals e = y − Xβ̂; hat matrix H = X(XᵀX)⁻¹Xᵀ with leverages hii; studentized residuals ei/(σ̂√(1−hii)); Cook's distance Di = ei² hii / (q σ̂² (1−hii)²).

Remaining issue: young concrete varies relatively more, so variance is not perfectly constant on either scale. That is why every model below is judged by error on unseen recipes, which does not rely on that assumption.

Not fooling ourselves · 2

Every model sits an exam on unseen recipes

A model can memorise the data it was fitted on. So we lock away 85 whole recipes (orange) before fitting anything, and only use them at the very end. The same recipe tested at 7 and at 28 days always lands on the same side, so no answer leaks.

✓Simpler wins ties. Inside the training recipes we also hold out one tenth at a time (cross-validation) to choose how bendy the age curve should be. Adding more age terms barely moves the error, so we keep the simple curve.
Show the statistics

Method: model selection with AIC, BIC and grouped K-fold cross-validation (Lectures 14–15). Gaussian log-likelihood: −2ℓ̂ = n log(RSS/n) + n log 2π + n. AIC = −2ℓ̂ + 2k, BIC = −2ℓ̂ + k log n. CV: 10 folds formed from whole mixtures, error = mean squared error on log f.

AIC picks degree –, BIC picks –, the one-standard-error CV rule picks –. All CV errors lie within one SE of each other, so we use degree 2.

Finding 3 · Question 3

Left alone, the computer picks the 1918 ratio first

We give the lasso all eleven candidates: both ratios, all seven raw amounts and age. It has a budget: the stricter it is, the fewer ingredients it may use. Drag the slider from strict to free.

✓With the tightest budget only water / binder and age survive. Abrams' water / cement comes in later, then the raw amounts. The data rediscovers the physics on its own.
Show the statistics

Method: lasso and ridge (Lectures 14 and 16). Columns standardized, then

lasso: min ‖y − β₀ − Zβ‖² + λ Σ|βj|    ridge: β̂ = (ZᵀZ + λI)⁻¹Zᵀy

Solved by coordinate descent: each step is a soft-threshold S(z, λ/2) = sign(z)·max(|z| − λ/2, 0), which sets small coefficients exactly to zero. Ridge only shrinks, never drops. λ chosen by grouped 10-fold CV for the comparison on screen 6.

Why you can believe this

Four reasons to trust the result

✓

Graded on unseen recipes

Every number on screen 6 comes from recipes locked away before fitting, never from the data the model saw.

✓

We checked the leftovers

On the log scale the errors look like noise, nothing predicts below zero, and no single cylinder drives the fit.

✓

Simple beat fancy

AIC, BIC and cross-validation all say extra curve terms add almost nothing, so we did not over-fit.

✓

Physics and data agree

The lasso picks the ratio first, and the slope is the same using only 28-day tests.

So what should a builder do?

Control water per kilo of binder first: it matters more than anything else in the recipe. Slag is a good cement substitute if you can wait for strength; fly ash costs some strength even after a year.

What this cannot tell us

One lab's recipes (Taiwan, 1990s), not a controlled experiment: these are associations.
Typical miss is still ~15–20%: curing conditions and materials quality are not in the data.
Only ages 1–365 days and w/b 0.24–0.90; outside that range, predictions are guesses.
In the 44-term model, single coefficients are unstable (collinearity), so we interpret only the small models.
